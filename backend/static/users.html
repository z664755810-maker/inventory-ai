⚠️ 数据持久化说明（部署后用户信息丢失的解决方案）

Railway 免费层使用临时容器，每次重启都会清空 SQLite 数据。现已提供三种持久化方案，推荐前两种：

  1. ✓ 推荐：操作下方「📤 导出数据」保存为 JSON 文件 → 部署后「📥 导入数据」
  2. ✓ 推荐：在 Railway 添加 Volume（挂到 /data），设置环境变量 RAILWAY_VOLUME_MOUNT_PATH=/data，重启也不丢
  3. 只用 admin/admin（seed 自动重建）
